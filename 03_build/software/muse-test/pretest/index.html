使用说明
  1. 用 Chrome 或 Edge（电脑版）打开。Safari 和 Firefox 不支持 Web Bluetooth。
  2. 如果点"连接"没反应，或者顶部显示"安全环境：否"：在这个文件夹里打开终端，运行 python3 -m http.server 8000，再用浏览器打开 http://localhost:8000。
  3. 先关掉手机上的 Muse App（头环同一时间只能连一个设备）。长按头环按钮开机，灯开始闪烁后点"连接 Muse 2"。
  4. 佩戴：前额的传感器贴紧皮肤（擦掉油脂、拨开刘海），耳后的电极贴紧耳后皮肤。等 1–2 分钟让信号稳定。
  5. 没有头环时，可以点"模拟模式"先熟悉界面（模拟数据会在闭眼时增强 α 波，并随机产生眨眼）。
  6. 信号质量是根据最近 1 秒波形估算的，仅供参考：佩戴初期、说话、咬牙、转头都会变差。
